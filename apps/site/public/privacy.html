Privacy policy — 嫦娥 / Change Dark

Effective date: 2026-03-30 · Operator: open-source project luban-ws/change-dark (see repository on GitHub) · Contact / support: GitHub Issues

本政策适用于 Chromium 系浏览器中的「嫦娥 Change Dark」扩展；须与 Chrome 网上应用店开发者后台「隐私权实践」勾选及说明保持一致。如有冲突，以实际扩展行为与本页及后台披露为准。

1. What this extension does

Change Dark is a Manifest V3 extension with a single user-facing purpose: to apply forced dark appearance and related readability options (theme modes, filters, typography, optional per-site CSS) on websites, according to settings chosen in the popup / options UI.

2. Data we process (and how)

  • Extension settings — Stored locally with the chrome.storage API (e.g. global on/off, theme mode, filter values, site list patterns, per-site overrides). Not transmitted to servers operated by the publisher for core functionality.
  • Tab and page context — The active tab’s URL / origin may be read so the popup, toolbar actions, and keyboard shortcuts can apply rules to the page you are viewing. This matches the behavior described in the Chrome Web Store listing and in-product UI.
  • Page-derived information for theming (Dynamic mode) — To compute dark theme colors, the content script reads computed style information (such as background colors) from elements in the page, within documented sampling budgets. Processing runs in your browser (including WebAssembly). It is not sent to the publisher’s servers as part of that feature.

Under the Chrome Web Store User Data FAQ, this type of on-page processing can constitute handling of sensitive user data categories (e.g. website content/resources). This policy and the Developer Dashboard disclosures describe that handling transparently.

3. Data we do not sell; transfers

We do not sell personal information. We do not use or share user data for personalized, re-targeted, or interest-based advertising. We do not operate the core extension atop a first-party login or account database.

If you open an external link from the optional support / “Buy Me a Coffee” section in the popup, you leave the extension UI; that site’s terms and privacy policy apply.

4. Limited use of user data (Chrome Web Store)

The publisher complies with the Chrome Web Store Limited Use of user data requirements. In particular:

  • Allowed use — Permissions and data access are used only to provide or improve this extension’s single-purpose, user-facing forced-dark and related UI features described in the store listing and the extension itself.
  • Allowed transfer — Any transfer of user data would be limited to what is necessary to provide that functionality, to comply with law, for security (e.g. abuse investigation), or as part of a permitted transaction of assets—consistent with Google’s Limited Use policy. The extension’s normal operation does not transmit your browsing or page content to the publisher’s backend for theming.
  • Prohibited advertising — No use of user data for personalized or interest-based ads.
  • Prohibited human interaction — No routine human access to identifiable user browsing content; any support would follow policy exceptions (e.g. explicit consent for a specific support case).

5. Permissions (alignment with Chrome disclosure)

  • storage — Persist your settings locally.
  • <all_urls> (host permission) — Inject the content script and apply styles on http(s) pages you visit, according to your configuration; also allows reading sensitive tab properties (such as URL) for matching tabs when required by the extension APIs, as explained in Chrome’s tabs permission documentation.

上架时「权限理由」须与本节一致；若将来缩减主机模式，请同步更新 manifest 与本页。

6. Remote code

The published package does not execute remotely hosted JavaScript logic: WebAssembly and scripts are bundled with the extension package, consistent with Manifest V3 requirements.

7. Security

Settings are stored using the browser’s extension storage APIs. If any future version transmits personal or sensitive user data off-device, such transmission would use modern transport security (e.g. HTTPS) as required by applicable Chrome program policies.

8. Children

The extension is general-purpose desktop browser software; it is not specifically directed at children under 13.

9. Changes

This policy may be updated when behavior or legal requirements change. The effective date at the top will be revised. Continued use after updates constitutes acceptance of the revised policy where permitted by law.
