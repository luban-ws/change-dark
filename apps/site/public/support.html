Open a Support Request on GitHub →

How to Report an Issue

To help us resolve your problem quickly, please include the following details in your report:

  • Affected URL: The specific website where Selena isn't displaying correctly.
  • Browser Version: Your Chrome or Edge version (e.g., Chrome 123.0.x).
  • Selected Mode: Whether you are using Dynamic, Static, or Filter mode.
  • Screenshots: Visual evidence of the rendering issue is extremely helpful.

Frequently Asked Questions

  • Why does a page flash white? Selena injects styles as fast as possible, but if a site is very heavy, you might see a brief flash. Try enabling Static mode for faster rendering on simple pages.
  • It broke a website's layout! Some sites have complex JS-based coloring. You can disable Selena specifically for that site by clicking the toolbar icon and toggling the switch.
  • Is my data safe? Yes. All calculations are performed 100% locally on your machine via WebAssembly. We never track or upload your browsing history.
