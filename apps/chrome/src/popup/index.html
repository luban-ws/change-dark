仅当前站（RFC 016）

「全局」下模式与主题滤镜写入全站默认；「仅当前站」写入当前 origin 覆盖，未写的项跟全局。需 http/https 页面。

主题模式

默认使用 Filter（整页 CSS 反相）。Dynamic / Static 为实验性 WASM 路径；滤镜链顺序见下方滑块。

各模式说明

Filter / Filter+：整页反相；Filter+ 在 Chromium 上常用 SVG 滤镜，Firefox 等会降级为 CSS Filter。大页更耗性能；已偏暗的站点可能被提亮。跨域 iframe 内无法注入。

Dynamic（实验性）：采样背景色 + k-means + WASM。Static（实验性）：固定基色、无采样、更省资源。

页面配色

作用于 Dynamic（实验性）/ Static（实验性）的底色与字色；Solarized 为固定 base03/base1。Filter / Filter+ 不改编页色，仅统一滚动条风格。

主题滤镜（RFC 011）

顺序：brightness → contrast → sepia → saturate；100% 为中性。

字体与描边（RFC 018）

可选增强暗底可读性；图标字体异常时请关闭「自定义字体」或清除此站覆盖。描边仅作用于常见文本节点，默认关闭。

每站自定义 CSS（RFC 019）

仅「仅当前站」且 http(s) 页可编辑；写入主文档样式表，不作用于 Shadow DOM 内与跨域 iframe 文档。勿粘贴不可信内容；过长内容会被截断。

站点列表（RFC 017）

一行一条：完整 https:// origin、hostname、段内 * glob（如 *.google.com、google.*），或 /pattern/flags 正则（正文尽量不含未转义的 /）。两种语义与 Dark Reader 一致。
