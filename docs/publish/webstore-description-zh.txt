【 嫦娥 (Selena)：专业级强制暗色引擎 】

嫦娥 (Selena) 是一款基于浏览器底层高性能算法构建的强制暗色扩展。它不仅仅是简单的滤镜反向，而是通过智能计算与像素级样式处理，将任何网页重塑为舒适、高保真的暗色界面。

【 为什么选择 嫦娥 (Selena)？ 】

● 高保真视觉重塑：我们尊重原始设计。Selena 会智能识别图片、图标和复杂的布局，仅对背景和文本对比度进行平衡处理。这意味着你看到的图片依然色彩真实，而页面背景则深邃如夜。

● 极致性能体验：加载大型复杂站点时不再卡顿。我们将核心颜色计算逻辑封装在 Rust / WebAssembly 模块中。这种接近原生的执行速度确保了暗色样式的毫秒级注入，为你带来丝滑的浏览体验。

● 隐私零泄露承诺：作为一款基于 Manifest V3 的现代扩展，我们秉承隐私至上的原则。Selena 的所有规则匹配和样式处理均在您的本地计算设备上完成，不通过任何远程服务器。

● 精细化的按站管控：您可以为特定的域名设定专属模式。支持 Dynamic (动态采样)、Static (静态基色) 与 Filter (滤镜) 三种策略，让您根据不同网站的特点，量身定制最佳的阅读氛围。

【 核心特性 】

- 一键开关：支持手动切换或自动同步系统暗色主题。
- 高性能渲染：由内置 WASM 内核驱动，零延迟，无闪烁。
- 无广告、无追踪：致力于纯粹、专注、安全的暗色阅读体验。

体验 嫦娥 (Selena)，让您的每一次阅读都充满质感。
