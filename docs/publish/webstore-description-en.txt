【 Selena — Professional High-Fidelity Forced Dark Engine 】

Selena is a high-performance dark mode extension powered by advanced on-device calculations. Unlike generic filter-based tools that simply invert colors, Selena intelligently analyzes page context to provide a balanced, high-fidelity dark UI that respects the original design intent.

【 Why choose Selena? 】

● High-Fidelity Visuals: We prioritize design integrity. Selena intelligently identifies images, icons, and complex components, only balancing the backgrounds and text contrast. This ensures your images remain vivid and accurate while the backgrounds fade into a deep, comfortable dark.

● Native Performance Experience: No more lag when loading complex websites. We've optimized the core coloring logic into a Rust / WebAssembly module. This native-level execution ensures millisecond-level style injection for a smooth, fluent browsing experience.

● Zero-Tracking Privacy: Built on the modern Manifest V3 platform, Selena is committed to a privacy-first experience. All rule processing and style calculations run 100% locally on your computer—no browsing data ever leaves your device.

● Granular Per-Site Control: Fine-tune your experience for individual domains with per-origin overrides, whitelist/blacklist patterns, and optional site-specific CSS fixes.
